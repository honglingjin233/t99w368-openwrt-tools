# modem5g 插件界面截图

> 截图来自实机(OpenFi6C)浏览器渲染 1920×1080 固定视口,中文界面。

## 文件
| 截图 | 内容 |
|------|------|
| `dashboard.png` | 仪表盘：连接状态/信号/速率/流量/温度 + 趋势图 + 宿主机状态 |
| `network-status.png` | 网络状态：信号强度、网络参数、载波聚合/小区、基本信息、PING 时延、数据面 |
| `network-config.png` | 网络配置：拨号设置(APN)、制式选择、小区锁定、频段锁定 |
| `atdebug.png` | AT 调试：只读 AT 命令终端 + 信道分析 |
| `system.png` | 系统设置：看门狗状态/事件、LED 联动、端口转发与防火墙(只读) |

## 隐私处理说明
- 已对截图中的**真实模块序列号(SN)、公网 IP、IPv6 地址**进行高斯模糊打码
- **IMEI/ICCID/IMSI 前端本身已掩码显示**(如 `3551****282`),非明文
- **`sms`(短信中心)截图未公开**：该页含真实个人短信(话费账单、来电号码等),属高敏内容,不适合放入公开仓库。如需演示短信功能,请在实机用测试卡生成脱敏短信后再截。

截图仅供界面展示参考,不代表当前实机实时数据。
