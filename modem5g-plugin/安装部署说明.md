# modem5g 插件安装部署说明（T99W368 / OpenFi6C，v5 多模组 + B 方案前端）

> 插件为 LuCI 2.x 前端 + rpcd ucode 后端，**无需编译**，直接部署源码文件。
> OpenFi6C = OpenWrt 官方 snapshot（apk 包管理），管理 IP 192.168.21.1。
> v5 = 多模组适配（T99W368/FM350-GL/RM500Q-CN）+ B 方案 6 Tab 前端；详见 MODULE_ADAPTER_v5.md 与 B方案迁移实装说明.md

## 文件清单（权威版本）
| 文件 | 部署位置 | 说明 |
|------|---------|------|
| `modem5g.uc.v4` | `/usr/share/rpcd/ucode/modem5g` | rpcd ucode 后端 v5 多模组（**权威，勿用旧 modem5g.uc**）|
| `modem5g_b_migration/status.view.js` | `/www/luci-static/resources/view/modem5g/status.js` | B 方案 6 Tab 前端（**权威，勿用主目录 status.js/v4.js**）|
| `modem5g-acl.json` | `/usr/share/rpcd/acl.d/luci-app-modem5g.json` | ACL（read/write + modem5g_extra）|
| `m5g-scan.sh` | `/usr/bin/` | 网络扫描后台脚本（PID 文件状态机）|
| `m5g-reset-restore.sh` | `/usr/bin/` | 复位后自动恢复（索引校准 + ifup）|
| `m5g-sms-back.sh` | `/usr/bin/` | 收信模式 120s 自动回 5G 兜底 |
| `m5g-watchdog.sh` | `/usr/bin/` | 数据面看门狗（真实连通验证 + 4G 收信跳过）|
| `m5g-at.sh` | `/usr/bin/` | AT 查询（ADB 通道，T99W368 用）|
| `m5g-at-serial.sh` | `/usr/bin/` | AT 查询（USB 串口通道，FM350/RM500 用）|
| `m5g-dev.sh` | `/usr/bin/` | MM 索引 → sysfs 物理路径（device 校准，防索引漂移）|
| `m5g-diag.sh` | `/usr/bin/` | 一键诊断报告（后台生成 /tmp/m5g-diag.txt）|
| `m5g-led.sh` | `/usr/bin/` | 5G LED 状态联动（亮=已连接）|
| `m5g-signal-guard.sh` | `/usr/bin/` | 智能选网（5G 信号弱自动切 4G，阈值可配）|
| `m5g-traffic.sh` | `/usr/bin/` | 月度流量统计（每日基线记录 /tmp/m5g-traffic.log）|

## 部署步骤（SSH root）
```sh
# 1. 后端（传后校验语法 + 重启 rpcd）
cat modem5g.uc.v4 | ssh root@192.168.21.1 'cat > /usr/share/rpcd/ucode/modem5g && ucode -c /usr/share/rpcd/ucode/modem5g && /etc/init.d/rpcd restart'
# 注意：rpcd 重启后插件注册延迟约 8-10 秒；★ ucode 目录勿放 .bak 文件（会被 rpcd 同名加载覆盖）

# 2. 前端（B 方案 6 Tab）
cat modem5g_b_migration/status.view.js | ssh root@192.168.21.1 'cat > /www/luci-static/resources/view/modem5g/status.js'

# 3. ACL
cat modem5g-acl.json | ssh root@192.168.21.1 'cat > /usr/share/rpcd/acl.d/luci-app-modem5g.json'

# 4. 脚本（全部 chmod +x）
for s in m5g-scan.sh m5g-reset-restore.sh m5g-sms-back.sh m5g-watchdog.sh m5g-at.sh m5g-at-serial.sh m5g-dev.sh m5g-diag.sh m5g-led.sh m5g-signal-guard.sh m5g-traffic.sh; do
  cat $s | ssh root@192.168.21.1 "cat > /usr/bin/$s && chmod +x /usr/bin/$s"
done

# 5. 看门狗开机自启（rc.local，必须在 exit 0 之前）
ssh root@192.168.21.1 'sed -i "/m5g-watchdog/d" /etc/rc.local; sed -i "/exit 0/i setsid sh /usr/bin/m5g-watchdog.sh >/dev/null 2>&1 &" /etc/rc.local'

# 6. 菜单挂载（若未挂载）
# /usr/share/luci/menu.d/ 下建 lucinew-app-modem5g.json：
# {"admin/status/modem5g": {"title": "5G 模块", "action": "view", "depends": {"acl": ["luci-app-modem5g"]}}}
```

## 依赖（OpenFi 官方 snapshot）
- rpcd + ucode 插件支持（`apk add rpcd-mod-ucode` 或系统自带）
- ModemManager + libmbim（官方源 `apk add modemmanager libmbim mbim-utils`，**需自补 usbmisc hotplug 脚本**）
- adb（AT 查询用）：从 OpenWrt 21.02 `adb_android.5.0.2_r1-3_aarch64_cortex-a53.ipk` 提取二进制 + `libopenssl1.1`（libcrypto.so.1.1）+ libgcc_s.so.1（工具链提取），放 `/usr/bin/adb` + `/usr/lib/`
- coreutils-stty（AT 串口备用）

## 验证
- 页面：`http://192.168.21.1/cgi-bin/luci/admin/status/modem5g`（菜单 状态→5G 模块）
- 后端：`ubus call modem5g status` / `ubus call modem5g temp` / `ubus call modem5g at_cmd '{"cmd":"ATI"}'`

## 回滚
- 插件文件删除即回滚（LuCI 前端 404 不影响系统）；看门狗脚本移除 rc.local 行
- 配置备份：`uci export network`（wwan 接口）
